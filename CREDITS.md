## Bring your own media

The example asset library under [examples/asset-library/](examples/asset-library/) ships
as **folder structure and descriptors only**. Music, ambience, and SFX slots are
deliberately empty: the resolver locates a clip by scanning its slot folder, so you
supply your own audio by dropping a file into the matching folder.

See [examples/asset-library/README.md](examples/asset-library/README.md) for the layout and
[examples/asset-library/REQUIREMENTS.md](examples/asset-library/REQUIREMENTS.md) for the
slots that example project expects.

Media you add is ignored by git (see [.gitignore](.gitignore)) — it stays on your machine
and is never committed, so no attribution obligation from your sources ever propagates
into this repository. If you do commit media deliberately, add a row to the table above
recording its origin and licence.

## Assets previously removed from this repository

The following were present in earlier working trees and are **not** carried here, because
their provenance could not be established.

- `examples/asset-library/` — 4 files (`music_bed.mp3`, `park_daytime.mp3`,
  `footsteps_running.mp3`, `heavy_breathing.mp3`). `heavy_breathing.mp3` carried BWF
  metadata naming a **ZOOM Handy Recorder H2** dated **2007-01-04**, the signature of a
  third-party field recording rather than material recorded for this project
- `audio_engine/audio/ambience/` — 9 files (`park.mp3`, `lake_night.mp3`, `lake_water.mp3`,
  `wind_in_trees.mp3`, `soft_lake_waves.mp3`, `soft_wind_leaves.mp3`, `leaves_rustling.mp3`,
  `bird_park.mp3`, `platform_night.wav`)
- `audio_engine/audio/sfx/shadowless/` — 3 files
- `audio_engine/audio/Music/shadowless/shadow.mpeg` — carried an FFmpeg (`Lavf`) transcode
  signature on a `.mpeg` container, which is inconsistent with a direct download from a
  stock-audio library
- `audio_engine/audio/voice/` — 24 TTS-generated dialogue clips, omitted for size rather
  than licence (they are test fixtures for scripts that no longer live under `tests/`)
