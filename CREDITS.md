### Note on `heavy_breathing.mp3`

The source WAV carried BWF metadata identifying a **ZOOM Handy Recorder H2**, dated
**2007-01-04** — eighteen years before this project began. That is the signature of a
third-party field recording rather than material recorded for this project. It is most
likely a Freesound download; if so, check whether its licence is CC0 (no attribution
needed) or CC-BY (attribution mandatory) before publishing.

## How to complete this file

For each `NEEDS SOURCE` row:

1. Find the original download page (Freesound, Pixabay, or wherever it came from).
2. Record the **direct URL**, the **uploader's name**, and the **exact licence**.
3. Replace the placeholder cells. Use this shape:

   ```
   | `path/to/file.mp3` | 12s | [Freesound #123456](https://freesound.org/s/123456/) by *username* | CC-BY 4.0 | Yes — credited here |
   ```

4. If you cannot establish the origin of a file, **delete the file** and source a
   CC0 replacement. An undocumented asset is a liability, not an asset.

## Assets deliberately excluded from this repository

The following were present in the original working tree and were **not** carried over,
because their provenance could not be established at import time. They remain available
in the original workspace if their licences are later confirmed.

- `audio_engine/audio/ambience/` — 9 files (`park.mp3`, `lake_night.mp3`, `lake_water.mp3`,
  `wind_in_trees.mp3`, `soft_lake_waves.mp3`, `soft_wind_leaves.mp3`, `leaves_rustling.mp3`,
  `bird_park.mp3`, `platform_night.wav`)
- `audio_engine/audio/sfx/shadowless/` — 3 files
- `audio_engine/audio/Music/shadowless/shadow.mpeg` — carried an FFmpeg (`Lavf`) transcode
  signature on a `.mpeg` container, which is inconsistent with a direct download from a
  stock-audio library
- `audio_engine/audio/voice/` — 24 TTS-generated dialogue clips, omitted for size rather
  than licence (they are test fixtures for scripts that no longer live under `tests/`)
