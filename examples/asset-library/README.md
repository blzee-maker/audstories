# Example asset library — bring your own media

This directory shows the **shape** of an asset library, not a bundle of audio. The
music, ambience, and SFX slots are intentionally empty: you supply the audio.

No third-party media is redistributed here, so there is nothing to attribute and
nothing to license before you can run the example. See [../../CREDITS.md](../../CREDITS.md).

## Layout

Each slot is one folder. The folder name encodes scene and descriptor; `DESCRIPTOR.txt`
records what the slot is asking for.

```
examples/asset-library/
├── music/scene_000_scene_1_neutral_high/        DESCRIPTOR.txt   ← drop music here
├── ambience/scene_000_scene_1_park_daytime/     DESCRIPTOR.txt   ← drop ambience here
├── sfx/scene_000_scene_1_footsteps_running/     DESCRIPTOR.txt   ← drop a sound effect here
├── sfx/scene_000_scene_1_heavy_breathing/       DESCRIPTOR.txt   ← drop a sound effect here
└── voice/scene_000_scene_1_narrator/clip_000/   SCRIPT.txt, voice.wav
```

## Adding your own audio

1. Open the slot folder and read `DESCRIPTOR.txt` (or `SCRIPT.txt` for voice) to see what
   the scene needs.
2. Drop one audio file into that folder. **The name does not matter** — the resolver takes
   the first matching audio file in the folder.
3. Run `asset-engine status` to check which slots are still empty.

Files you add are covered by `.gitignore` and stay on your machine. The one exception is
`voice/.../voice.wav`, a short clip generated by the project's own TTS pipeline, kept as a
worked example of a filled slot.

[REQUIREMENTS.md](REQUIREMENTS.md) lists every slot this example project expects, and is
regenerated by the pipeline rather than edited by hand.
